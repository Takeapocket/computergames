# 爱恩斯坦棋第一阶段临时规则假设

由于本届 QQ 群附件、棋谱标准和统一平台协议尚未确认，本阶段只在 `core/` 中实现以下临时规则。后续正式规则如有差异，优先修改核心规则引擎，不把规则逻辑写入 GUI 或 AI。

1. 棋盘为 5x5。
2. 双方各有 6 枚棋子，编号 1-6。
3. 双方初始布局暂时允许由代码传入，本阶段不强制固定开局。
4. 红方目标角为右下角。
5. 蓝方目标角为左上角。
6. 红方每步可向下、右、右下移动一格。
7. 蓝方每步可向上、左、左上移动一格。
8. 如果目标格为空，则正常移动。
9. 如果目标格有对方棋子，则吃掉对方棋子。
10. 不允许移动到己方棋子所在格。
11. 掷出骰子点数 `d` 时，如果己方编号 `d` 的棋子存活，则必须移动该棋子；如果该棋子已被吃掉，则可选择编号距离 `d` 最近的存活棋子；如果两侧距离相同，则两个棋子都可选。
12. 一方任意棋子到达自己的目标角，或吃掉对方全部棋子，立即获胜。

当前未确认事项：

- 是否存在组委会强制开局布局。
- 棋谱是否有统一格式。
- 是否有统一平台协议或现场 API。
- 一方无合法走法但未触发胜负时如何裁定。本阶段仅返回空合法走法。

## 比赛时间限制

来源：2026-05-09 通过 web search 调研中国大学生计算机博弈大赛历届公开资料（2026 校赛通知 PDF 仅写"采用倒时计，在规定时间内完成比赛"，未明确分钟数；具体规则官方指向 http://computergames.caai.cn/，但访问时证书校验失败）。

- **当前主流：每盘每方用时 4 分钟 = 240 秒，超时判负。**
- 历史上有 3 分钟版本（180 秒），不同年份/赛季可能不同。
- 每轮双方对阵最多 7 盘，先胜 4 盘为胜方。
- 两盘中间不休息；两场比赛中间休息 ≤10 分钟可调参数。

代码默认值：`gui/timer_panel.py:DEFAULT_TOTAL_SECONDS = 240.0`，与 4 分钟版本一致。
若届时官方公告为 3 分钟，启动时加 `--total-seconds 180` 即可，无需改代码：

```bash
.venv/Scripts/python.exe scripts/run_gui.py --total-seconds 180
```

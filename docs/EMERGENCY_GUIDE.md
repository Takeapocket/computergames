# 爱恩斯坦棋应急手册

更新时间：2026-10-18。配套：[操作清单](MATCH_CHECKLIST.md)、[赛事要求](COMPETITION_COMPLIANCE.md)。

## 使用边界

研究环境可自行悔棋、恢复和调试。正式比赛出现误操作、计时、崩溃或网络问题时，先报告裁判；只有获准后才修正、暂停、恢复或更换设备。自动保存是数据保护能力，不免除崩溃判负，不保证裁判允许继续比赛。

默认只提示超时；裁判确认后使用相应的“裁判判红方/蓝方超时负”按钮。只有裁判要求程序自行判负时才启用自动超时判负。不得把暂停计时当作延长思考时间的手段。

## 保存失败

- 开局或走子后出现自动保存失败时，当前内存局面不等于已经落盘。先检查目标目录权限、磁盘空间和文件占用，并尝试“保存棋谱”另存到可写位置。
- 整轮结算保存失败会进入待保存状态，保留单盘恢复文件，并暂停进入下一盘。点击“重试保存”；成功前不要新建下一盘或退出覆盖恢复材料。
- 重试不重复记分。若持续失败，保存可读取的原文件与当前棋谱，并由裁判确认比分和后续处理。

## 崩溃或恢复异常

1. 正式比赛先告知裁判，记录最后确认的局面、比分和计时。
2. 重启前备份 `replays/auto_save.json` 和 `replays/auto_save_match.json` 到新的故障目录，保留原字节。不要先删除、编辑或用新盘覆盖文件。
3. 获准恢复后运行：

   ```powershell
   & ".venv/Scripts/python.exe" "scripts/run_gui.py"
   ```

4. 根据提示选择恢复，并核对双方棋子、行棋方、骰子阶段、比分、盘号和计时。恢复成功不等于比赛结果被裁判认可。
5. 单盘与整轮恢复文件不匹配或内容校验失败时，不手工拼接比分。保存故障副本，使用独立复盘或工程排查；正式赛果由裁判决定。

既有启动路径会清理部分损坏的自动保存文件，因此故障取证必须在重新启动之前备份。文件大小不能判断是否有效，也不能据此推断原子写入失败。

## 录入错误

- 未执行：确认正确骰子或对手实际走法；正式比赛更正前取得裁判许可。不能在看到推荐后重掷骰子，也不能由人替代 AI 重新选我方策略。
- 已执行：许可后使用悔棋或加载已确认快照。悔棋仅限当前盘内记录，不跨已经结算的盘；计时不会随棋谱撤销而返还。
- 多步混乱：先另存故障快照，再处理。加载棋谱或切换模式会改变当前上下文，不要直接覆盖唯一证据。
- 明确标注其他规则版本的棋谱可查看/回放，不能直接续写为当前规则；如要研究该局面，另建当前规则棋谱并保留来源。无版本旧档不自动升级成新规则实验。

骰子规则：对应号存活时必走该子；否则可选较小一侧最大存活号和较大一侧最小存活号，两侧无须等距。缺 4、5 时掷 4 可走 3 或 6。GUI 已校验合法性，但“合法”不能证明它就是对方实际走出的那一步。

## 推荐显示“计算中”或界面无响应

AI 推荐在后台计算。变更骰子、走子、悔棋或加载后，旧结果会作废。研究时可手动试走；正式比赛应等待程序结果，不能利用任意合法步列表由人替代程序决策。

若界面持续无响应，先报告裁判并保存可用的外部记录。不要在比赛中打开控制台调用私有方法、强行修改内存或擅自结束进程。裁判允许重启时按前面的备份与恢复步骤处理。

## 无法启动

赛前工程排查使用项目虚拟环境读取报错：

```powershell
& ".venv/Scripts/python.exe" "scripts/run_gui.py"
& ".venv/Scripts/python.exe" "scripts/smoke_test.py"
```

- 缺少 Tk：检查安装的 Python 是否包含 Tcl/Tk；在赛前准备环境并重新验证。
- 虚拟环境启动器存在但基础 Python 路径失效：恢复或重建对应环境，不把它误判为游戏代码错误。
- smoke 通过仅说明该规则/状态路径通过，不能据此认定 GUI 渲染与整轮操作都正常。
- 正式比赛不临时安装依赖、改系统配置或自行换机；由裁判决定处理方式。

## 网络与平台问题

按目标场次的正式规程处理。离线场次误联网应立即停止连接并告知裁判；不能因为程序不使用网络，就推断“通常不判负”。`ipconfig` 中的某种地址也不足以证明所有网络接口已经断开。

如赛事明确指定线上平台，先确认平台协议与网络要求；当前 `adapters/` 没有正式平台实现，不能直接认定已适配。

## 重要文件

| 用途 | 路径 |
|---|---|
| 单盘恢复 | `replays/auto_save.json` |
| 整轮恢复 | `replays/auto_save_match.json` |
| 手工棋谱 | `records/` |
| GUI 启动 | `scripts/run_gui.py` |
| 规则与版本 | `core/rules.py`、`docs/RULE_ASSUMPTIONS.md` |
| 最新审查与验证 | `reports/project_review_20261018.md` |

恢复材料的归档应使用新目录，不复用既有实验或故障目录。真实棋谱进入研究数据集时存放在 `E:\computergame-data`，保留原始来源与规则版本。

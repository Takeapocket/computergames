# 新版桌面 UI 效果稿

日期：2026-10-18

[打开交互效果稿](desktop-preview.html)。该文件自包含，不使用 CDN、网络字体或外部资源，可以直接用浏览器打开。

## 本轮范围

效果稿展示 PySide6 单盘样机的视觉方向，不是已接通程序的界面。页面始终标记“界面效果稿 / 示例状态”，仅支持骰子选择、选中棋子及固定落点标记的视觉切换，不执行走子、不运行 AI、不读写棋谱。空棋谱区没有虚构对局记录，推荐区没有虚构评分、胜率或耗时。

真实样机应调用现有 core、AI 和 GameRecord。当前规则版本以 `core.rules.RULES_VERSION` 为准；P14 默认参数、JSON 棋谱结构和旧 Tk 界面继续保留。七盘制、完整计时及比赛流程不属于最小样机，本轮不为它们设计可点击入口。

## 视觉与布局

采用浅色桌面工具风格，以棋盘为主体。顶部只放程序标识、预览版说明与效果稿状态；左侧为 5×5 棋盘，右侧依次放当前行动方、骰子选择、推荐信息；底部棋谱保留一条稳定阅读区域。

| 项目 | 规范 |
|---|---|
| 目标桌面视口 | 1200×850；大屏内容最大宽度 1280px |
| 桌面外边距 / 内容间距 | 32px / 22px |
| 操作栏宽度 | 316px；较窄桌面缩至 290px |
| 卡片 | 白底、16px 圆角、1px 边框，阴影仅作轻微区分 |
| 页面背景 / 正文 | `#F3F5F7` / `#182735` |
| 操作强调色 | `#0F766E`，用于骰子选中、棋子选框和落点 |
| 红 / 蓝棋子 | `#D85B59` / `#427BB4`，白色数字 |
| 棋盘浅格 / 深格 | `#F7F8FA` / `#E9EEF0` |
| 字体 | 系统 Segoe UI、Microsoft YaHei UI 回退；无网络字体 |
| 键盘与可访问性 | 原生按钮、明确 aria-label、aria-pressed 和焦点环；状态更新使用 aria-live |
| 窄屏 | 750px 以下纵向排列，棋盘保持正方形；侧栏改为局部双列再接推荐区 |

HTML 和 Qt 分别使用各自的布局系统，允许适当调整尺寸以保证原生窗口中的字体、缩放及控件可读性，不要求逐像素一致。效果稿的手机响应式用于便于审阅设计，不表示桌面 EXE 已支持手机。

## 布局与状态来源

初始布局逐项取自 `ai/opening_layouts.py` 的 `PRESETS["balanced_v1"]`。视觉坐标为 A–E 与 1–5，对应内部列 0–4、行 0–4；这是显示转换，不更改棋谱坐标或规则语义。

| 方 | 1 号 | 2 号 | 3 号 | 4 号 | 5 号 | 6 号 |
|---|---|---|---|---|---|---|
| 红方 | A1 | B1 | C1 | A2 | B2 | A3 |
| 蓝方 | E5 | D5 | C5 | E4 | D4 | E3 |

默认示例为开局、红方行动、骰子 3，选中 C1。C2、D1、D2 三个固定标记仅用于演示落点样式。切换其他骰子只改变选中棋子，不在此 HTML 中另写一套合法步规则。实际 Qt 样机的合法步、推荐与胜负均由现有引擎返回。

## 样机实现对照

- 主窗口保留同样的棋盘、操作栏、棋谱视觉层次。
- 未掷骰时明确提示输入骰子；推荐未运行时保持空状态。
- 计算、失败、过期推荐和保存失败均展示真实状态，不能以默认值伪装成功。
- 本轮最小样机可另加真实接通的新建、打开与保存入口；本效果稿不提供假文件操作。
- 旧界面继续用于完整比赛流程；新旧界面通过同一棋谱格式互通。

## 本轮效果稿验证

已用浏览器实测 1200×850 和 390×844 两个视口并查看完整截图。桌面布局在视口内完整显示；窄屏纵向滚动，无横向溢出。页面生成 25 个棋格、12 枚棋子和 6 个骰子按钮；切换 6 点后选中红 6，点击“重置演示”后回到 3 点。此验证只覆盖 HTML 设计稿，不能替代 PySide6 窗口、EXE 启动或棋谱兼容性验收。
